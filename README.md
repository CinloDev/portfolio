## 🏗️ Architecture & Engineering Highlights

- **Next.js 16 App Router with Turbopack:** Fast HMR, server-side layout streaming, and instant routing transitions.
- **Bilingual Internationalization (i18n):** Native Spanish & English localization with automatic locale detection, cookie persistence, and header actions switch.
- **Strict TypeScript (Zero Build Errors):** Strict type safety across the entire application with 100% clean compilation (`tsc --noEmit`).
- **Core Web Vitals & Performance Focus:**
  - Zero runtime re-renders on static and animated components.
  - Native lazy-loading for below-the-fold media assets.
  - Font optimization using `@next/font/google` (`Poppins` and `PT_Sans`) with zero layout shift (CLS: 0).
- **SEO & Structured Data:**
  - Google-compliant `schema.org/Person` and `schema.org/WebSite` JSON-LD structured data.
  - Dynamic `generateMetadata` with project-specific OpenGraph images and localized meta tags.
  - Standardized canonical URLs across all dynamic and static routes.
- **Accessible & Adaptive UI:**
  - Accessible theme switcher (Light / Dark mode) with semantic HSL CSS variables.
  - Radix UI primitives with full keyboard navigation and ARIA landmarks.

## 💻 Local Development

### Prerequisites

- **Node.js**: `v18.18.0` or higher (recommended: `v20.x` or `v22.x`)
- **Package Manager**: [`pnpm`](https://pnpm.io/) (`v9.x`+)

### 1. Clone the Repository

```bash
git clone https://github.com/CinloDev/portfolio.git
cd portfolio
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Run Development Server

```bash
pnpm dev
```

The application will be available at **`http://localhost:9002`** (running on Next.js with Turbopack).

### 4. Quality Checks & Production Build

```bash
# Verify strict TypeScript compilation
pnpm typecheck

# Run Next.js linter
pnpm lint

# Create optimized production build
pnpm build

# Start production server
pnpm start
```

## 📁 Directory Structure

```
portfolio/
├── public/
│   ├── assets/              # Logos, portraits, icons, and CV previews
│   ├── images/              # Project screenshots and showcases
│   ├── cintialosada-cv-es.pdf # Spanish CV document
│   ├── cintialosada-cv-en.pdf # English CV document
│   ├── robots.txt           # SEO robots instructions
│   └── sitemap.xml          # XML sitemap index
├── src/
│   ├── ai/                  # Genkit AI workflows and configuration
│   ├── app/                 # Next.js App Router (pages, layouts, and routes)
│   │   ├── components/      # Page-level sections (Hero, Experience, Work, etc.)
│   │   ├── privacidad/      # Privacy Policy route
│   │   ├── projects/        # Projects index and dynamic [id] detail routes
│   │   └── terminos/        # Terms of Service route
│   ├── components/          # Reusable shared components (Header, Footer, UI primitives)
│   │   └── ui/              # Radix UI + Tailwind design tokens (Button, Card, Form, Toast)
│   ├── hooks/               # Custom React hooks (useToast)
│   ├── lib/                 # Structured portfolio data, image assets, and utility functions
│   └── locales/             # i18n localization dictionaries (es.json & en.json)
├── next.config.ts           # Next.js configuration
├── package.json             # Dependencies and project scripts
├── tailwind.config.ts       # Tailwind CSS design system configuration
└── tsconfig.json            # Strict TypeScript configuration
```
